# RSS 阅读功能

Daily Signal 的「订阅与文章」提供常规阅读和订阅管理操作。

## 阅读与筛选

- 未读文章使用较粗的标题，已读文章使用较轻的标题。列表和预览均支持切换已读 / 未读、收藏 / 取消收藏。
- 打开预览或安全的原文链接会自动标记已读。在预览中手动标为未读后，连续阅读时保留这个选择；重新打开该文章时再次自动标记已读。
- 来源、分组、搜索、阅读状态和「只看收藏」可以组合使用。搜索同时匹配标题和正文，不区分大小写。
- 可以按发布时间选择最新或最早优先。每页显示 50 篇，改变筛选或排序后返回第一页；预览的上一篇 / 下一篇沿用打开时的全部筛选结果顺序，能够跨分页阅读。
- 批量标为已读匹配全部当前筛选结果，包含其他分页。按钮中的数字是将受影响的未读文章数。后台新增的文章也按提交时的同一筛选规则匹配。
- 缓存文章不再截断为最近 500 篇，较早的收藏和搜索结果仍可访问。应用沿用完整本地状态查询，分页控制渲染数量，不是服务端分页。
- 保存失败时保留原阅读状态，由应用通知展示错误。

## 订阅管理

订阅按分组展示并显示未读数；空分组显示「未分类」。编辑按钮可修改自定义名称和分组。来源刷新仍更新原始标题、站点和文章，自定义名称及分组保留。OPML 导出使用显示名称和当前分组。

删除订阅仍沿用确认对话框：同时删除缓存文章及阅读状态，已归档日报和来源快照保留。

## 快捷键

| 按键      | 作用                            |
| --------- | ------------------------------- |
| `/`       | 在文章列表中聚焦搜索            |
| `J` / `K` | 在阅读预览中切换下一篇 / 上一篇 |
| `M`       | 切换当前文章的已读状态          |
| `S`       | 切换当前文章的收藏状态          |
| `Esc`     | 关闭阅读抽屉                    |

输入框、文本域、下拉框和可编辑文本内不触发阅读快捷键；组合键也不触发。

## 持久化与升级

迁移 `0007_workable_tombstone.sql` 为缓存文章增加 `read_at` 和 `starred`，为订阅增加 `custom_title`。旧缓存文章初始为未读且未收藏，旧订阅保持原显示名称。启动时沿用现有版本化迁移机制，状态保存到本地 SQLite。

文章刷新更新正文与发布时间，保留已读时间和收藏。归档快照的阅读字段可缺省，升级不会改写已有日报或其来源。Web 和桌面客户端共用这些业务实现；本次没有修改原生桌面入口或安装包。

共享筛选定义位于 `packages/domain/src/reader.ts`，前端列表和服务端批量操作复用同一匹配规则。RPC 提供 `articles.update`、`articles.markRead`、`feeds.update`，输入使用严格 schema 校验；缺失文章或来源返回 `NOT_FOUND`，无效输入返回 `BAD_REQUEST`。

回归覆盖旧库升级、重启、刷新状态保留、大于 500 篇的缓存、批量筛选边界、RPC 输入拒绝、收藏及阅读交互、保存失败、排序分页、快捷键和订阅编辑。整页 Storybook 场景覆盖桌面和窄屏间距审查。
