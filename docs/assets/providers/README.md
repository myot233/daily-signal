# Provider icon sources

Selected, unmodified SVGs from `@lobehub/icons-static-svg@1.95.0` (MIT), downloaded from the npm registry. The upstream copyright notice is included in `LICENSE`.

- Catalog: https://icons.lobehub.com/
- Source: https://github.com/lobehub/lobe-icons
- Package: https://www.npmjs.com/package/@lobehub/icons-static-svg/v/1.95.0

These assets support the provider design proposal and local prototype. They are not loaded from a remote CDN at runtime. Logos identify their respective brands; a generic gateway uses a neutral symbol rather than an invented brand logo.
